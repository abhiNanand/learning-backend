What is WebSocket?
It is a communication protocol provides bi-directional communication over a singhle tcp connection, allowing for low latency and real time data transfer.
To impletement this in node js we use (socket io) library.bi-directional communication channel between a client and a server. This means that the server can push messages to clients. Whenever you write a chat message, the idea is that the server will get it and push it to all other connected clients.
