io ka kaam:

naye users ko listen karna

sab clients ko message bhejna

rooms / namespaces manage karna

🔹 io.on() ka matlab
io.on(eventName, callback)

Ye bilkul Node.js ke event system jaisa hai.
👉 Meaning:
“Jab ye event ho, tab ye function chalao”

🔹 'connection' event kya hota hai?
 connection ek event hai jb koi client server se socket connection banata hai tab connection trigger hota hai. 

🔹 socket kya hai?
(socket) => { ... }
👉 socket = ek single connected user
Har user ke liye:
naya socket object banta hai
uska unique id hota hai
uske events hote hain

socket.id = unique user id. 

Some more events example 
io.on('connection', (socket) => {
  console.log('user connected:', socket.id);

  socket.on('message', (data) => {
    console.log('message from client:', data);
  });

  socket.on('disconnect', () => {
    console.log('user disconnected:', socket.id);
  });
});
//  io.on diffrent events ko handle karta hai

What is socket?

socket is a live connection object.

You use it to:

// receive data from server

  console.log(data);
});

// send data to server
